# Contract: Versioned configuration files

Every file below lives at the repository root, except `.github/commit-scopes`. A change to any of
them marks all modules as touched in the pull request workflow (FR-014).

## `versions.env`

`KEY=value` lines, `#` comments, no quotes and no spaces around `=`. The Makefile reads it with
`include`, scripts with `. ./versions.env`, and workflows with `grep -v '^#' versions.env >>
"$GITHUB_ENV"`.

| Key | Example | Used by |
|-----|---------|---------|
| `GO_VERSION_OLDEST` | `1.26` | test matrix, `structure`, `go.work` |
| `GO_VERSION_NEWEST` | `1.27` | test matrix and single-version jobs |
| `GOLANGCI_LINT_VERSION` | `v2.14.0` | `lint.sh` version check, `golangci-lint-action` |
| `GORELEASE_VERSION` | `v0.0.0-20260824195058-e88cd73687aa` | `go install golang.org/x/exp/cmd/gorelease@…` |
| `TRIVY_VERSION`, `TRIVY_SHA256` | `0.75.0`, `<hex>` | `install-tool.sh trivy` (linux/amd64 tarball) |
| `GITLEAKS_VERSION`, `GITLEAKS_SHA256` | `8.30.1`, `<hex>` | `install-tool.sh gitleaks` |
| `BEARER_VERSION`, `BEARER_SHA256` | `2.1.1`, `<hex>` | `install-tool.sh bearer` |
| `SEMGREP_IMAGE` | `semgrep/semgrep:1.178.0@sha256:<hex>` | `semgrep` job container |

## `.module-exceptions`

Whitespace-separated columns. Everything after the third column is the justification, which is
required. `#` starts a comment line.

```text
# module    kind       value                        justification
retry       coverage   70                           generated table code is exercised only via fuzzing
fsnotify    platforms  linux/amd64,linux/arm64      relies on inotify; README states Linux-only support
```

Validation, by `structure-check.sh` and by readers:

- the module exists;
- `kind` is `coverage` or `platforms`;
- a coverage value is an integer from 0 to 79;
- platforms are valid `GOOS/GOARCH` pairs from the six supported ones;
- the justification is not empty;
- no duplicate (`module`, `kind`) pair.

## `.github/commit-scopes`

One scope per line, `#` comments allowed. Scopes are lowercase, match `^[a-z0-9][a-z0-9._-]*$`,
and must not equal a module directory. Initial content: `ci`, `deps`, `docs`, `repo`, `specs`.

## `.golangci.yml`

golangci-lint v2 configuration (`version: "2"`). The linter set and its mapping to Principle IV
are in [research.md R-05](../research.md#r-05-linter-configuration-golangci-lint-v2).
Module-specific overrides are forbidden unless justified (constitution, Repository layout).

## Scanner ignore and config files

Each tool's own mechanism (FR-023). Every entry carries a comment with its justification.

| File | Tool | Format |
|------|------|--------|
| `.trivyignore` | Trivy | one advisory ID per line, preceded by a `#` justification line |
| `.gitleaksignore` | Gitleaks | one finding fingerprint per line, preceded by a `#` justification line |
| `.semgrepignore` | Semgrep | gitignore syntax; replaces Semgrep's defaults, so it re-lists needed defaults; per-line `nosemgrep: <rule-id>` comments in code are also allowed |
| `bearer.yml` | Bearer | config: `report: security`, `fail-on-severity: critical,high,medium,low,warning`, `skip-path: [specs, scripts/tests]` |
| `bearer.ignore` | Bearer | JSON managed by `bearer ignore add <fingerprint> --comment "<justification>"`; created only when the first suppression is needed |

## `go.work` / `go.work.sum`

Generated by `make work` and committed. They are not read by any gate. See the data model for
the content rules.

## `.gitignore`

Adds the local tool directory and the generated artifacts: `/bin/`, `/sbom/`, `*.cdx.json`,
`cover.out`.
